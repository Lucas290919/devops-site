Docker

Containerização de aplicações modernas

💻 O que é Docker?

Docker é uma plataforma open-source que permite criar, distribuir e executar aplicações dentro de containers. Um container é um ambiente isolado que contém tudo o que sua aplicação precisa para rodar: código, runtime, bibliotecas e configurações.

A grande vantagem? Se roda na sua máquina, roda em qualquer lugar.

⚙ Como funciona?

  • Dockerfile — Receita para construir a imagem
  • Image — Snapshot imutável da aplicação
  • Container — Instância rodando da imagem
  • Registry — Repositório de imagens (Docker Hub)
  • Docker Compose — Orquestra múltiplos containers

Exemplo: Dockerfile básico

Dockerfile 
FROM node:18-alpine

WORKDIR /app

COPY package*.json ./
RUN npm install --production

COPY . .

EXPOSE 3000

CMD ["node", "server.js"]

Docker Compose: Aplicação + Banco de dados

docker-compose.yml 
version: '3.8'
services:
  app:
    build: .
    ports: ["3000:3000"]
    environment:
      - DB_HOST=db
    depends_on: [db]

  db:
    image: postgres:15
    environment:
      - POSTGRES_PASSWORD=secret

Terraform

Infrastructure as Code para o mundo moderno

🌏 O que é Terraform?

Terraform é uma ferramenta de Infrastructure as Code (IaC) da HashiCorp que permite definir, provisionar e gerenciar infraestrutura em múltiplos provedores cloud usando uma linguagem declarativa chamada HCL.

Com Terraform, você versiona sua infraestrutura como código, tornando-a reproduzível e auditável.

📄 Comandos essenciais

  • terraform init — Inicializa o projeto
  • terraform plan — Mostra o que será criado
  • terraform apply — Aplica as mudanças
  • terraform destroy — Remove os recursos
  • terraform state — Gerencia o estado

Exemplo: EC2 + Security Group na AWS

main.tf 
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "web" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"

  tags = {
    Name        = "WebServer"
    Environment = "production"
  }
}

output "instance_ip" {
  value = aws_instance.web.public_ip
}
